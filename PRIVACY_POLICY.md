# NightShift Privacy Policy

Effective date: 14 September 2026

NightShift is a browser extension published by **OzzyApps**, maintained by [Ozzy on GitHub](https://github.com/ozzy-apps). Privacy contact: **[info@ozzymail.nl](mailto:info@ozzymail.nl)**.

## What NightShift does

NightShift changes webpage colors using the dark-mode palette you choose. It supports global colors, saved presets, website-specific themes, and exclusions for pages you want to leave unchanged.

## Information processed on your device

NightShift reads page and embedded-frame addresses to decide whether to apply dark mode and which saved website theme to use. It reads webpage styling, CSS resources, and page structure to calculate and apply replacement colors. This processing takes place in your browser. NightShift does not record the contents of your forms or maintain an archive of your page content or browsing history.

NightShift stores these preferences in local Chrome extension storage:

- Whether dark mode is enabled, your nine color choices, and your accent preference.
- Custom preset names and their colors.
- Website addresses you explicitly save with a website theme, together with that theme's colors and accent preference. Website themes store the exact hostname and any non-default port. Local file themes store the file path. Query strings and fragments are not saved in website themes.
- Exclusion rules you add. A rule may include a hostname, path, or query string if you enter one.

NightShift does not use Chrome cloud sync, analytics, advertising trackers, or an extension account. Saved settings are not sent to OzzyApps or to an analytics or advertising service.

## Network requests

To theme a page, NightShift may request CSS stylesheets from the websites or resource hosts serving that page. Those hosts receive ordinary network-request information, such as your IP address, under their own privacy practices. Same-origin page requests may use the browser's existing credentials for that origin. The extension's fallback CSS requests omit credentials and the referrer. Stylesheet responses may be cached temporarily in memory to support rendering; NightShift does not send them to a developer-operated server.

All NightShift executable code is included in the installed extension. It does not download remote executable programs.

## Imports and exports

Export creates a JSON file on your device containing your settings, custom presets, website themes, and exclusions. This file can contain website addresses or local file paths you saved. You decide whether to share it. Import reads the backup you select and replaces settings only after you choose to apply it. NightShift does not upload either file.

## Donations and external websites

The Donate button opens PayPal only when you click it. PayPal handles the donation and any associated payment information under its own privacy policy. NightShift does not read or store payment-card details. A donation is optional and does not unlock extension functionality.

If you contact the publisher directly, your message and contact details are used to answer your request. They are separate from the extension's local settings.

## Use and sharing

NightShift uses locally processed information only to provide its visible dark-mode features. It does not sell user data, use it for advertising, or use it to determine creditworthiness or lending eligibility. Page content and browsing records are not transmitted to the publisher for human review. NightShift's use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Your control and retention

You can edit or remove saved presets and exclusion rules in the popup. To remove a website theme, open that website and click its selected palette button. Turning NightShift off restores the page styling while retaining your saved settings for later use. Uninstalling the extension removes its local extension storage. Exported files remain wherever you saved them until you delete them yourself.

Chrome also lets you restrict the extension's site access and decide whether it may access local file URLs. Restricting access can limit styling on affected pages or frames.

## Changes and contact

This policy will be updated if NightShift's handling of information changes. For privacy questions, contact **[info@ozzymail.nl](mailto:info@ozzymail.nl)**.
